NekoYakuSS 工具

名詞表轉換器

把 Google Sheets 的韓中對照貼進來 → 產出 NekoYakuSS 可匯入的名詞表 JSON。一格用 ／ 塞的多個寫法會自動拆成獨立詞條、各自配對譯名；變體與譯名數量對不上的列會標「待確認」讓你核對。

① 貼上試算表

在 Google Sheets 選「韓文原名 + 建議譯名」兩欄，整段複製貼上（欄以 Tab 分隔）

② NekoYakuSS 名詞表 JSON

貼上資料後，這裡會即時產生 JSON。
產出格式：{ "terms": [ { "term": 韓文, "zh": 中譯, "type": 分類 } ] }。
匯入時會併進「你當下打開的那本書」（不看檔案裡的 bookId），同名詞以匯入的為準覆蓋。標了待確認的列會在該筆加 note 提醒——匯入後可在名詞表裡直接改。全程在你裝置本機運算，資料不外傳。
